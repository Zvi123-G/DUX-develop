# טכנולוגיות בפרויקט ואופן הרצה

## טכנולוגיות בפרויקט

בפרויקט זה נעשה שימוש בשתי טכנולוגיות עיקריות:

1. **React** - ספריית JavaScript לבניית ממשקי משתמש. React משמשת ליצירת צד הלקוח (Frontend) של האפליקציה.
2. **Flask** - פריימוורק Python קל משקל לפיתוח צד השרת (Backend). Flask משמש לניהול ה-API ולחיבור בין צד הלקוח לבסיס הנתונים.

## אופן הרצה

כדי להריץ את הפרויקט, יש לבצע את השלבים הבאים:

### התקנת צד הלקוח (Frontend)

1. ודא ש-Node.js מותקן במחשב שלך.
2. פתח את הטרמינל ונווט לתיקיית צד הלקוח:
    ```bash
    cd /c:/Users/<you-user>/DUX-develop/frontend/tours-website
    ```
3. התקן את התלויות באמצעות הפקודה:
    ```bash
    npm install
    ```
4. הרץ את צד הלקוח במצב פיתוח:
    ```bash
    npm start
    ```
    האפליקציה תיפתח בדפדפן בכתובת [http://localhost].

### התקנת צד השרת (Backend)

1. ודא ש-Python מותקן במחשב שלך.
2. התקן את Flask ואת התלויות הנדרשות:
    ```bash
    pip install flask
    ```
3. נווט לתיקיית צד השרת (אם קיימת) והרץ את השרת:
    ```bash
    python server.py
    ```
    השרת יפעל בכתובת [http://localhost:5000].

### חיבור בין צד הלקוח לצד השרת

ודא שכתובת ה-API בצד הלקוח מוגדרת כראוי כך שהיא תצביע לכתובת השרת ([http://localhost:5000]).

לאחר ביצוע השלבים הללו, האפליקציה תהיה מוכנה לשימוש.
